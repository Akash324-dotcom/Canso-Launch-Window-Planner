# Requirements map, slide text to component to automated test

Gate G4 of issue 5. Every row of the slide text in `SLIDE.md` is listed once, with the
screen or component that implements it and the exact automated test that covers it. The
rule of the issue is that a requirement without a test is not done, so a row whose test
column says NOT DONE is a known gap and appears in `DONE.md` as well.

Run the tests named in the last column with:

```bash
cd frontend
npx vitest run tests/<file>.test.js
```
